# Improx Data — Enterprise Data & Admin Theme

A custom-built WordPress theme engineered specifically for **Improx Data** (`improxdata.com`), structured around the **Data & Admin** operations business model.

## The 6 Main Services Built-In:
1. **Data Entry** — High-precision document keying, OCR error verification, mortgage & healthcare file digitization (99.94% accuracy SLA).
2. **Web Scraping** — Automated web data harvesting, daily competitor SKU price intelligence, and structured feeds.
3. **Data Processing** — Enterprise database deduplication, multi-format PDF/EDI parsing, and CRM hygiene (Salesforce, HubSpot).
4. **Data Analytics** — Executive Power BI dashboards, Tableau visualization, and automated KPI reporting.
5. **Administrative Assistant** — Dedicated executive virtual assistants, inbox & calendar management, billing reconciliations, and back-office queue processing.
6. **Data Services** — Turnkey cloud data lake ingestion, Snowflake/BigQuery migration, and AI/ML training data labeling.

## Inbuilt CMS & Custom Fields (No ACF Pro Required):
* **Custom Post Type: Services (`/service/`)** with native custom fields for service category, deliverables checklist, and SLA guarantee badges.
* **Custom Post Type: Case Studies (`/case-studies/`)** with native custom fields for headline ROI metrics (e.g. `99.94%`, `1.2M`, `800K+`), client industry, and tech stack tags.
* **Custom Post Type: Testimonials** with executive client names, designations, and company names.
* **4-Stage Dual-Verification QA Protocol** interactive flowchart.
* **Lead Generation**: Interactive "Request Project Batch Evaluation" scoping form.

## Installation on Hostinger WordPress:
1. Go to `https://improxdata.com/wp-admin`.
2. Navigate to **Appearance → Themes → Add New Theme → Upload Theme**.
3. Select `improx-theme.zip` from this directory.
4. Click **Install Now** and **Activate**.
5. Set the homepage: **Settings → Reading → A static page → Select "Home"**.
